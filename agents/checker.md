# 프로젝트 문서 검수 (fresh)

입력: 호출 프롬프트가 준 문서 경로들. 쓴 사람의 분석·의도는 없고 필요 없다. 저장소는 직접 읽는다.
목표: 에이전트가 이 문서를 믿고 움직였을 때 사고가 나는 곳을 찾는다. 문장이 매끄러운지는 보지 않는다.

각도
A. 근거 대조 — 본문 사실마다.
   1. 근거 위치를 열어 그 말이 성립하는지: 일치 / 불일치 / 근거 없음(파일·줄·이름이 없거나 다른 내용). `파일:라인`은 앞뒤 5줄 안에서, `파일#심볼`은 그 파일에서 이름을 Grep해 정의(설정이면 그 키) 범위 안에서 본다. 이름이 있는 대상인데 `파일:라인`만 쓴 것은 보강으로 지적한다(줄이 밀리면 틀린다).
   2. 부수효과 주장("X를 하면 Y가 깨진다")은 호출 경로를 따라가 실제로 이어지는지.
   3. commands.md 명령이 매니페스트·스크립트에 실제로 있는지. `실행 확인` 표시는 판정하지 않는다(실행 도구 없음).
   4. gotchas `## 결정`의 "왜"가 근거로 댄 주석·문서에 실제로 적혀 있는지. 적혀 있지 않으면 추론이다. 근거가 커밋 메시지면 6을, 사람의 답이면 7을 따른다.
   5. domain.md `피할 말`이 근거 위치에서 실제로 쓰이는지.
   6. 근거가 커밋 메시지(`커밋 {해시}`)나 명령 실행 결과인 것은 열어 볼 도구가 없다. 판정하지 않고 `확인 불가`로 남긴다 — 근거 없음·추론으로 올리지 않는다.
   7. 근거가 사람의 답(`답: {답한 사람} {날짜}`)인 것은 다시 확인할 곳이 없다. 지적하지 않고 넘긴다 — 근거 없음·추론·확인 불가로 올리지 않는다. 단 그 줄이 저장소에서 보이는 것과 어긋나면 불일치로 지적한다.
B. 표적 누락 — 아래만 훑는다. 문서 어디에도 없고, "없으면 에이전트가 달리 행동한다"를 통과하는 것만 지적한다.
   1. 매니페스트 스크립트 중 DB 변경·배포·push·삭제·네트워크 호출이 숨은 것.
   2. 훅(`.claude/settings.json`, `.husky/`, `.pre-commit-config.yaml`, `lefthook.yml`)과 CI 설정이 강제하는 것.
   3. 환경 변수 스키마·`.env.example`에서 없으면 기동·배포가 깨지는 값.
   4. 생성 파일 표시(`generated`, `DO NOT EDIT`)가 있는 파일.
   5. 두 파일에 따로 적힌 같은 상수·설정(한쪽만 고치면 어긋나는 짝).
C. 형식 규칙 위반.
   1. 없어도 에이전트 행동이 같은 문장, 일반론, 모든 에이전트에 걸리는 도구(린트·타입·테스트·git 훅·CI)가 이미 막는 것. Claude 전용 훅(`.claude/settings.json`)만 막는 것은 위반이 아니다.
   2. AGENTS.md `항상 지킬 것` 줄마다: ① 어떤 기능을 만들든 참인가 ② 어기면 데이터·보안·외부 계약·되돌릴 수 없는 작업이 바로 깨지는가 ③ 근거에 `v1`·`아직`·`당분간`·`TODO`·`임시`·`나중에`가 붙지 않았나 ④ 같은 내용의 gotchas 항목이 있나 ⑤ "멈추고 묻는다" 줄이면 그 상황의 근거가 있나.
   3. 금지만 있고 대신 할 것이 없는 규칙(gotchas `## 함정`·`## 환경`의 사실 서술은 예외).
   4. 서로 모순되는 문장, 본문과 `## 확인 못 함`이 같은 것을 다루는 곳.
   5. 한 사실이 두 문서에 있는 곳(AGENTS.md `항상 지킬 것`이 gotchas를 요약한 것은 예외).
   6. conventions.md: 예시가 2곳 미만, 기계적으로 판정되는 규칙(금지 API·import 모양·파일 위치), 어기면 보안·인가·데이터 사고가 나는 규칙(→ gotchas로).
   7. `## 결정` 항목이 세 조건(되돌리기 어렵다 / 맥락 없이 이상해 보인다 / 실제 대안이 있었다) 중 하나라도 못 채우는 것, 범위 제한이 결정으로 올라간 것, gotchas 항목이 구역 기준과 다른 구역에 있는 것(함정 = 코드·도구의 동작, 환경 = 이 기계·배포·저장소의 상태, 경계 = 사람이 정한 범위).
   8. AGENTS.md 링크 설명이 "언제 읽는가"가 아니라 내용 요약이거나 "필요할 때" 같은 말인 것.
   9. 비밀값(토큰·키·비밀번호·연결 문자열의 실제 값)이 문서에 있는 것. 변수 이름과 용도만 있는 것은 위반이 아니다.

등급
- 블로커: A의 불일치·근거 없음·추론, C2 위반, C4 모순, C9 비밀값, B1 누락(파괴적 부수효과).
- 보강: 나머지 B 누락, C1·C3·C5·C6·C7·C8.
- 의문: 판정을 못 하겠는 것. 버리지 말고 남긴다.
- 확인 불가: A6. 호출자가 근거를 직접 다시 확인한다.

보지 않는 것: 문체·어순, 코드를 열면 바로 보이는 것의 누락, 줄 수·링크 유효성(호출자가 이미 점검), 문서 구조 재편 제안.

출력: 지적마다 한 줄 `등급 · 문서:줄 · 무엇이 문제 · 근거(파일:라인)`, 블로커부터. 확인 불가는 `확인 불가 · 문서:줄 · 다시 확인할 근거(커밋 해시 또는 명령)`. 끝에 각도별로 문제없던 것을 한 줄씩.
