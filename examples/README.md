# 예시: 작업 문서 한 건

[`loan-cancel-ready.md`](loan-cancel-ready.md)는 요청 하나가 계획부터 종결까지 지나간 뒤의 작업 문서예요. signoff가 `.claude/work/done/`으로 옮긴 상태 그대로예요.

> 도서 대출 시스템은 설명하려고 지어낸 거예요. 파일 경로, 줄 번호, 명령 결과도 모두 지어낸 값이에요. [`docs/guide.md`](../docs/guide.md)에 나오는 "대출 준비 취소" 예시와 같은 작업이에요.

## 이 문서가 만들어진 순서

1. `/baton:draft 도서 대출 준비를 취소할 수 있게 해 줘` — 질문 하나(예약 순번)에 사람이 답하고, 게이트1에서 멈춰요.
2. `/clear`로 대화를 비워요. 구현은 작업 문서만 보고 해요.
3. `/baton:implement loan-cancel-ready` — 구현이 끝나면 inspect가 이어서 리뷰하고, 게이트2에서 멈춰요.
4. 사람이 `## 인계`의 사람 테스트를 직접 해 봐요.
5. `/baton:signoff loan-cancel-ready` — 테스트 결과를 기록하고 문서를 `done/`으로 옮겨요.

## 절마다 쓴 단계와 볼 곳

| 절 | 쓴 단계 | 이 예시에서 볼 곳 |
|---|---|---|
| 헤더 · `## 배경` · `## Spec` · `## 계획` | draft | `검증 수단:`·`준비:`와 Task의 Verify가 implement가 실행할 수 있는 명령의 전부예요. 이 예시는 `준비: 없음`이에요 |
| `## 검증` | draft (doubter) | 처음 Verify는 버튼을 조건 없이 그려도 통과했어요. doubter가 이것을 잡았고, draft가 `확인:`으로 바꿨어요 |
| `## 구현 메모` | draft | 새 세션의 구현자가 다시 찾느라 헤맬 것만 적었어요 |
| `## 구현` | implement, inspect | `loan-history.ts`는 계획에 없던 파일이라 `### 계획 밖 변경`에 남았어요. `### 수정 1회차`는 inspect가 블로커를 고친 기록이에요 |
| `## 리뷰 1회차` · `## 리뷰 2회차` | inspect (reviewer) | reviewer는 diff와 AC만 받았어요. 1회차에서 사서 권한 확인이 빠진 것을 Critical로 잡았어요. 2회차는 새 reviewer가 고친 부분만 봤어요 |
| `## 인계` | inspect (게이트2), signoff | 게이트2에서 사람에게 보인 글과 같아요. 사람 테스트는 Spec의 1번에 구현·리뷰에서 드러난 2번·3번을 더했어요. `결과` 열은 signoff가 채웠어요 |
| `## 종결` | signoff | 사람 테스트 3번은 "안 함"으로 답해서 미검증으로 남았어요. 그래도 완료할 수 있어요. 이 한계는 [guide](../docs/guide.md) 8장 "현재 한계"에 있어요 |

게이트1에서 사람에게 보인 글은 작업 문서에 남지 않아요. 그 형식은 [guide](../docs/guide.md) 4.9절에 있어요.

## 작업 문서 밖에 남은 것

signoff는 작업 이력(`.claude/work/ledger.md`)에 한 줄을 덧붙여요.

```
| 날짜 | 작업 | 규모 | 리뷰 회차 | 사람 개입 | 누출 단계 | 비고 |
|---|---|---|---|---|---|---|
| 2026-11-02 | loan-cancel-ready | 정규 | 2 | 0 | 구현 | |
```

누출 단계는 `구현`이에요. 구현 메모가 형제 함수 `markReady()`를 가리켰는데, 구현 단계의 자가검증(형제 요소 점검)에서 권한 확인 누락을 거르지 못하고 리뷰에서 잡혔기 때문이에요.

누출 단계가 `없음`이 아니므로, 프로젝트에 `docs/agent/`가 있으면 signoff 보고에 주의 사항 제안이 붙어요. 사람이 승인해야 `gotchas.md`에 들어가요.

```
주의 사항 제안: 상태를 바꾸는 함수에서 requireLibrarian()을 빼면 · 회원 계정으로 상태가 바뀐다 · 리뷰 1회차 Critical, src/loans/ready.ts:13
```
